# Plan

## Core idea
If *everyone* reads the same essay, it can do something no ordinary essay can:
create **common knowledge** — everyone knows, and knows that everyone knows.
That's the essay's main lever. Use it in three ways:

1. Close the gap between what humanity knows and what each family knows
   (cheap, life-saving facts: ORS, drowning, roads, tobacco, smoke, vaccines,
   newborns, asking about suicide).
2. Correct false beliefs we hold *about each other* (pluralistic ignorance;
   exaggerated meta-perceptions of opponents; the loud few online).
3. Say a few things about how to live that hold across cultures
   (being wrong well, children, giving, pain, relationships, power).

## Constraints for a universal reader
- Plain words, short sentences, translatable, few idioms.
- Not partisan; not Western-centric; not condescending to the poor.
- Only claims I'm confident are true; hedge numbers; cite sources at the end.
- Address people in pain directly and gently.
- Pay off the common-knowledge premise repeatedly (esp. "the person you tell
  has read this too").

## Structure
0. Opening — the premise; traffic light; promise of honesty
1. Most suffering is not a mystery (child mortality 43% -> ~4%; ORS story)
2. Things that save lives
3. We agree more than we think (pluralistic ignorance, footbinding)
4. The people you hate are mostly not who you think (meta-perceptions,
   outrage economy, dehumanising language)
5. How to be wrong
6. Children (no hitting, talk to babies, body safety, girls' schooling)
7. If you have more than you need (giving)
8. If you are in pain right now
9. What lasts (relationships)
10. To those with power
11. Tomorrow (list) + closing
