# Common Ground

A small city. A shared future. **Common Ground** is a complete, turn-based strategy game about building a community where everyone can thrive. Across ten weeks, balance limited time and supplies, respond to forecasts, and invest in four very different neighborhoods.

## Run

Open this folder in **Godot 4.7.2** and press **F6/F5** (or run the project from the Project Manager). From a terminal:

```sh
godot --path .
```

The project uses the **GL Compatibility** renderer, needs no plugins or downloads, and is suitable for a web export.

## How to play

- Pick one of the five project cards, then click a neighborhood to carry it out.
- You get **3 time** each week. Supplies carry over, with 2 more arriving each week.
- The forecast shows what happens **when you end the week**. Green space, trust, and preparedness soften different challenges.
- Gardens and high-trust neighborhoods also provide small benefits every week.
- After Week 10, aim for **65 Wellbeing**, **45 Trust**, **40 Green Space**, and every neighborhood at **50+ local wellbeing**. Fairness improves your final score.

### Controls

Mouse: all actions. **1–5**: select a project. **Left/Right**: change neighborhood. **Space**: apply selected project. **E**: end week. **H**: help. **Esc**: close a panel. **Enter**: start/continue.

## Why this game?

Its central lesson is practical: lasting wellbeing comes from meeting immediate needs *and* building trust, shared skills, and resilient places. Listening is free, preparation matters, and a city is not thriving if its most vulnerable neighborhood is being left behind.
