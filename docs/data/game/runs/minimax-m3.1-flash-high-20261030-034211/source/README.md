# Common Ground

A complete, asset-free cooperative stewardship game made in **Godot 4.7.2**. Care for seven shared districts over eight days, balancing nature and people. The game rewards choices that make a shared system healthier rather than simply maximizing personal gain.

## Run locally

1. Open this folder in Godot 4.7.2 and press **F6/F5**, or run:
   ```bash
   godot --path .
   ```
2. Choose an action, then click a district. Click **End Day** to advance. Press **1–4** to select actions and **Space** to end a day.
3. Meet the community targets to finish the 8-day promise.

The project uses the **gl_compatibility** renderer, has **thread support disabled**, and contains only Godot scenes, scripts, and generated vector/UI graphics. It is ready for a web export; no downloads, plugins, or external assets are required.
