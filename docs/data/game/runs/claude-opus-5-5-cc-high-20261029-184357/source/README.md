# Ripple

*A game about what we share, and why it matters.*

You live in the small town of Brindlewick. Posts arrive in your feed one at a
time. For each one you decide whether to **share it**, or whether **something's
off**. If something's off, you name the manipulation trick it uses. Your choices
ripple out across a network of neighbours, making them clear-minded or leaving
them in the fog.

Over seven chapters you learn the six most common manipulation techniques:
**Emotional Bait, Fake Expert, False Choice, Scapegoat, Personal Attack and
Cherry-Picking**. Just as important, you learn to recognise honest information
(named sources, a calm tone, admitting what isn't known, correcting mistakes),
because too much suspicion does harm too.

## Why this game

Research on "psychological inoculation" (Roozenbeek, van der Linden and others)
has found that practising how to spot manipulation techniques in a safe setting
helps people resist them in real life. Misinformation affects health, elections
and how neighbours treat each other, so if everyone played this game, almost
everyone would benefit. The game takes about 15 minutes, needs no reading
beyond everyday language, and ends with a pocket guide of seven questions to
ask before sharing anything.

## Running

1. Install [Godot 4.7](https://godotengine.org/) (standard build).
2. Open this folder in Godot (Project Manager → Import → `project.godot`) and press **F5**,
   or run from a terminal: `godot --path .`

The project uses the GL Compatibility renderer with no threads, so it can be exported to the web.

## Controls

| Action | Mouse | Keyboard |
| --- | --- | --- |
| Share a post | "Share it" | `S` |
| Flag a post | "Something's off" | `F` |
| Name the trick | Coloured buttons | `1`–`6` |
| Back | "Back" | `Esc` |
| Continue / start | Blue button | `Enter` / `Space` |
