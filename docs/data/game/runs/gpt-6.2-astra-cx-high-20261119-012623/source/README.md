# Common Ground

A neighborhood matching game set in Maple Ward. Read a resident's request, hear what nearby neighbors can offer, and connect people whose plans fit. Complete nine requests over three days.

Open this directory in Godot 4.7.2 and press **F5**. To play from a terminal, run `godot --headless --path . --editor --quit` once to import the artwork, then `godot --path .`.

Click or tap a map pin or offer card to meet a neighbor. Use **A**, **B**, or **C** to read an offer, **Enter** to connect or continue, and **Esc** to return. **Tab** and **Shift+Tab** navigate controls. The question-mark button opens the field guide and the speaker button toggles sound.

The project uses the Compatibility renderer. All artwork, sound, and game content are self-contained.
