# Bystander

Ten minutes of hands-on practice for the minutes before an ambulance arrives.

Most people who collapse, choke or bleed heavily are saved (or not) by whoever is standing
nearest. Bystander teaches that person what to do, by making them do it:

| Drill | What you practise |
| --- | --- |
| 01 Collapse | Check for response and spot gasping, point at one person to call, push to a 110 bpm beat until 30 compressions land on tempo (the beat goes silent halfway), place AED pads and shock |
| 02 Choking | Tell coughing from silent choking, five back blows, find the spot and give five abdominal thrusts |
| 03 Bleeding | Press and hold without peeking, add cloth on top, place a tourniquet |
| 04 Stroke | Run the Face / Arms / Speech test on a patient, and decide what to do when symptoms pass |
| 05 Out cold | Move a person into the recovery position in five moves; what not to do in a seizure |
| 06 Ten myths | Rapid-fire myth or true: burns, drowning, poison, heatstroke, snakebite and more |

Each drill ends with four words to remember, and finishing all six gives a one-page pocket card.

**Emergency mode** (the red button, always visible) skips the teaching: eight situations, large
numbered steps, the local emergency number, and a CPR metronome with a 30-count and a
two-minute swap reminder.

The emergency number is guessed from the device time zone (no network) and can be changed;
every instruction then uses it.

## Running

Open `index.html` through any static server, for example:

```sh
npx serve .
```

There is no build step for development. The page is plain ES modules:

- `main.js` — header, home page, closing card, view switching
- `drill.js` — the step engine shared by the drills; `drills/*.js` — one file per drill
- `emergency.js` — emergency mode
- `figure.js` — the posable pictogram people; `audio.js` — metronome and sound effects (Web Audio)
- `numbers.js` — emergency numbers by country; `state.js` — in-memory session state
- `style.css`, `fonts.css` — styles and the two embedded typefaces (Archivo, Atkinson Hyperlegible Next)

`fonts.css` is generated by `node tools/make-fonts.mjs` from the `@fontsource-variable` packages.
`tools/shot.mjs` and `tools/s/` are development helpers that click through the page in headless
Chrome.

It works offline, makes no network requests, and stores nothing.

## Accuracy and limits

The content follows public bystander first-aid guidance from the international resuscitation
councils (ILCOR, AHA, ERC) and the Red Cross / Red Crescent. It is a first lesson, not a
certificate: a screen can teach when and how, but only a hands-on class teaches how hard to push.
Emergency numbers were compiled by hand and can change; check your own. English only for now.
