# Good in Reach

An offline guide to small, practical ways to help people. Choose a time budget, pick an action, and make a plan. You can mark it done or copy the plan to keep it. Plans live in memory for the current visit.

To preview, run `python3 -m http.server 8000` in this directory and open `http://localhost:8000`. The entry point is `index.html`. The illustration and typefaces are embedded in JavaScript modules. Fraunces and DM Sans are distributed under the SIL Open Font License in `licenses/`.

To check module bundling, run `esbuild main.js --bundle --format=esm --outfile=/dev/null`.
