# Mend

A practice for the minute after something breaks.

If everyone got better at the second try — with their own body, with the person in front of them, and with whatever they can spare for preventable suffering — ordinary life would be less cruel, and fewer people would die of things we already know how to stop.

Open `index.html` through a static server (ES modules do not run from `file://`). Nothing is stored. Nothing is sent. No network is required after the page loads.

- **Here** — name the state you are in, then a physiological sigh, before you speak or send.
- **Near** — repair what you broke, stay with someone who is hurting, and recognize when an apology is the wrong tool.
- **Far** — blood, measured giving, and passing the skill on.
- **The words** — compose a repair you can actually say. Live notes flag the phrases that undo one.
- **In danger** — plain steps, and widely published crisis numbers, for you or for someone else.

The five moves: **Steady, Fact, Own, Hear, One.**
