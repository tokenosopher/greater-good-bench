Greater Good Bench

Can AI make something that would improve the world for the most people?

What gets measured in AI gets optimized, so this starts measuring it: frontier models are asked to make an SVG, a website, a 3D model, a game, an animation and an essay that, if everyone saw, used, played, watched or read it, would improve the world for the greatest number of people. Each prompt’s outputs are shown side by side with the full agent transcript, time, tokens and cost. Nothing is judged automatically: the ranking is the owner’s own, plus community votes.
